This project is a clone application structured using a multi-repository approach, where different repositories handle specific functionalities. The separation ensures modularity and better scalability.

Backend - Contains API endpoints.

Common - Handles Zod validation and shared utilities.

Frontend - Implements the user interface with skeleton-based loading.


Tech Stack:

Prisma - ORM for database management.

Tailwind CSS - Utility-first styling framework.

Cloudflare Workers - Used for hosting the backend.

Zod - Schema validation for input handling.

Skeleton-Based Loading - Enhances user experience by displaying loading placeholders.
